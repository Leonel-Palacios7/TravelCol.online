# Política de seguridad

## Reportar una vulnerabilidad

No abras un issue público. Usa el reporte privado de GitHub: pestaña **Security → Report a vulnerability** de este repositorio. Incluye los pasos para reproducirla y el impacto que observaste.

Respondemos el reporte y coordinamos la corrección antes de publicar detalles.

## Alcance

- La API (`apps/api`), la web (`apps/web`) y la infraestructura de `infrastructure/`.
- Los datos de demostración (`*@travelcol.local`) y las llaves `*_E2E_ONLY` son falsos a propósito y no constituyen una filtración.

Controles implementados y pendientes: [docs/seguridad.md](docs/seguridad.md).
